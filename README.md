**ガンダムオタクのサイド7！**  
ニュース、ガンプラ、トークのアプリ。AdSense広告＋RX-78青＋白デザイン！  
Xで#Side7Connect！

## 🌌 概要
- **ニュース**：GUNDAM.INFO RSSで最新アニメやイベント情報。
- **グッズ**：楽天APIでガンプラやグッズを最安値で。
- **コミュニケーション**：匿名フォーラム＋Firebaseチャット。
- **収益**：Google AdSenseで年50〜150万円目指す！

## 🛠️ 技術
- Frontend：Next.js 15, Tailwind CSS 4
- Backend：ASP.NET Core 9, PostgreSQL
- リアルタイム：Firebase
- デプロイ：Vercel (Frontend), Heroku (Backend)

## 🚀 セットアップ（Windows 11）
1. `git clone https://github.com/makki-color/side7connect.git`
2. Frontend：`cd frontend`, `npm install`, `npm run dev`
3. Backend：`cd backend`, `dotnet restore`, `dotnet run`
